# 🏠 AuxCorretor

### Organização, controle e produtividade para corretores de imóveis.

O **AuxCorretor** é uma aplicação voltada para auxiliar corretores de imóveis na organização de sua rotina profissional, centralizando informações e atividades que fazem parte do processo de atendimento e negociação.

A proposta é conectar, em um único sistema, os principais elementos do dia a dia do corretor:

**Clientes → Atendimentos → Visitas → Imóveis → Negociações**

---

## 💡 O projeto

A rotina de um corretor envolve acompanhar diversas pessoas, imóveis, conversas, visitas e oportunidades ao mesmo tempo.

O AuxCorretor nasce com a proposta de transformar essa rotina em um fluxo organizado, permitindo que o corretor acompanhe seus clientes e oportunidades com mais clareza e tenha um histórico das interações realizadas ao longo do processo.

O sistema também é pensado para atender diferentes cenários, desde o **corretor independente até equipes e imobiliárias**, criando uma base para uma futura plataforma SaaS.

---

## ✨ Principais funcionalidades

* 👥 Gestão de clientes
* 🏠 Gestão de imóveis
* 🤝 Acompanhamento de atendimentos
* 📅 Organização de visitas
* 📝 Histórico de interações
* 💰 Controle financeiro
* 🔐 Autenticação e controle de acesso
* 🏢 Suporte a corretores e imobiliárias

---

## 🧱 Construído para evoluir

O AuxCorretor está sendo desenvolvido com uma arquitetura que permita a evolução gradual do sistema sem comprometer sua base.

A aplicação utiliza tecnologias e práticas comuns no desenvolvimento de sistemas backend modernos, buscando manter o domínio organizado e as responsabilidades bem definidas.

### Stack

* ☕ **Java 21**
* 🌱 **Spring Boot**
* 🔐 **Spring Security**
* 🗄️ **PostgreSQL**
* 🧩 **Spring Data JPA / Hibernate**
* 🗺️ **MapStruct**
* 🐳 **Docker**
* 📖 **OpenAPI / Swagger**

---

## 🎯 Objetivo

O objetivo do AuxCorretor é construir uma solução capaz de acompanhar o corretor durante todo o seu processo de trabalho, desde o primeiro contato com um cliente até o acompanhamento das oportunidades e negociações.

Ao mesmo tempo, o projeto serve como uma oportunidade para explorar, na prática, **desenvolvimento backend, modelagem de domínio, segurança, persistência de dados e construção de uma aplicação SaaS**.

---

## 🚧 Desenvolvimento

O projeto está em desenvolvimento contínuo e sua arquitetura e funcionalidades evoluem conforme novos requisitos e necessidades do domínio são identificados.

A prioridade é construir uma base sólida antes de expandir a aplicação, permitindo que novos recursos sejam incorporados sem perder a organização do sistema.
